# RadioTrack Live

Statische RadioTrack-Web-App mit live laut.fm Senderdaten und beschränkter lokal protokollierter Airplay-Auswertung.

Dieser öffentliche Mirror enthält ausschließlich HTML/CSS/JavaScript, keine Zugangsdaten oder privaten Benchmarkdaten. Das Haupt-Repository bleibt privat.

Quelle: offizielle laut.fm API https://docs.api.laut.fm/.
